#UNDERGROUND DMZ

11인 팀

ENGINE
Unreal Engine
PLATFORM
HTC VIVE · 백팩 PC
ROLE

01PLAY STRUCTURE

4인 멀티 · 10×10m · 이동형 PC

네 명이 백팩 PC를 메고 실제 공간을 걸으며 플레이합니다. 두 명씩 P1, P2 두 팀으로 나뉘어 같은 층의 서로 다른 동선을 진행합니다.

실제 공간은 10×10m로 고정되어 있어서, 가상 맵을 0.5m 격자로 나눠 벽, 낮은 벽, 이동 지역, 문을 배치했습니다. 층은 지상 1층, 지하 1층, 지하 2층, 지하 화물층으로 구성했습니다.

02ROUTE SYNC

두 동선을 7개의 락으로 맞췄습니다

두 팀은 같은 층에서 서로 다른 동선을 진행합니다. 두 동선이 만나야 하는 지점 7곳에 락을 걸어, 먼저 도착한 팀은 늦은 팀이 올 때까지 다음 구역으로 넘어가지 못하게 했습니다.

기다리는 동안에는 먼저 도착한 팀 쪽에 적을 다시 생성해 플레이가 멈추지 않게 했습니다.

P1 테스트 소요00:00
P2 테스트 소요00:00

03TRIGGER · EVENT · NAV

언리얼 엔진 내 레벨 디자인을 직접 작업했습니다

  1. TRIGGER플레이어가 트리거 구역에 들어서면 이벤트가 시작됩니다.
  2. EVENT이벤트 위치와 속성 값을 언리얼 에디터에서 직접 배치하고 조정했습니다.
  3. NAV이벤트가 끝나면 다음 지점을 가리키는 네비가 켜집니다.

두 팀은 서로 다른 구역에서 출발해 각자 트리거와 이벤트를 거친 뒤, 마지막 공간에서 합류합니다. 동선을 벗어나는 경우의 예외 처리도 함께 설계했습니다. 전투 수치는 테이블로 분리해, QA 중에 담당자가 바로 고쳐 볼 수 있게 했습니다.

#HOW I WORK

PM을 함께 맡은 프로젝트에서는 진행 상황이 보드에서 바로 보이도록 협업 도구를 설계했습니다.

01NOTION · ALICE VR COASTER

컨펌 단계를 만들어 보드만 봐도 진행 상황을 알 수 있게 했습니다

기존 보드는 진행전, 진행중, 완료 세 단계뿐이어서 컨펌을 기다리는 작업과 실제로 작업 중인 태스크가 섞여 있었습니다. 네이버웍스와 스프레드시트에 흩어져 있던 협업을 노션 보드로 옮기고, 컨펌대기와 재작업중 단계를 새로 만들었습니다.

  1. CONFIRM완료로 가는 길은 컨펌 승인 하나로 두었습니다.
  2. REJECT반려할 때는 사유를 반드시 남기게 했습니다.
  3. LINK그래픽은 SVN 폴더, 개발은 git PR 링크를 태스크에 붙여 보드에서 바로 확인하게 했습니다.
  • 3→1주간 현황 확인 회의
  • 13%태스크 평균 작업시간 단축 (12분 32초 → 10분 55초)
  • 28주만에 출시 (목표 30주)

02JIRA · BIOPOP ELIXIR

규칙을 지키는 일은 자동화에 맡겼습니다

노션 보드에서는 기록을 사람이 직접 남겨야 했습니다. ELIXIR에서는 5개년 로드맵과 2주 스프린트를 Jira 한 곳에서 운영하면서 워크플로와 자동화를 직접 설계했습니다.

  1. STRUCTURE에픽, 컴포넌트, 레이블, 스프린트로 무엇을 누가 언제까지 하는지 나눴습니다.
  2. AUTOPR이 생성되면 컨펌대기로 넘어가고 컨펌 담당자에게 멘션이 갑니다. 반려되면 담당자에게 바로 알림이 갑니다.
  3. DATA리드타임, 반려 횟수, 견적 대비 실제 소요가 운영만으로 쌓여 다음 견적의 근거가 되었습니다.

쌓인 데이터는 업무 배분에만 쓰고 인사평가에는 쓰지 않았습니다.
